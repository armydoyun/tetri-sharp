# Tetri#

규칙(회전 시스템, 미노 생성기, 고정 방식, 중력…)을 직접 조합할 수 있는 낙하 블록 퍼즐.
HTML · CSS · JS로 만들고, 배포물은 **`index.html` 파일 하나**입니다.

기획: [docs/PLAN.md](docs/PLAN.md) · 디자인 시스템: [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md)

## 들어 있는 것

- **모드:** Sprint 40L · Marathon(150줄) · Ultra(2분) · Master(레벨 999, 500부터 20G) · Dig(쓰레기 10줄) ·
  Survival(올라오는 쓰레기 줄 버티기, 줄을 지우면 막음) · Endless
- **Survival 목표:** 30초·1분·2분·3분 구간을 도전하고, 결과에서 이전 최고와 비교하거나 같은 시드와 규칙으로 다시 시작합니다. 구조 연습에서는 게임 오버 몇 수 전으로 돌아가 버틴 시간과 막은 쓰레기 줄을 비교합니다.
- **오늘의 도전:** 날짜로 정한 시드의 Sprint 40L(Modern). 같은 날이면 누구나 같은 블록 순서이고, 오늘 최고 기록을 압축한 결과 코드·링크
  (`#daily=`)로 주고받아 상대 리플레이와 함께 달립니다. 날짜 선택에서 오늘을 포함한 최근 7일에 도전하고, 날짜별 최고 기록을 다시 보거나 공유할 수 있습니다
- **퍼즐:** 30단계. 정해진 판과 피스로 판 비우기(피스 1~4개) · T-spin Double · T-spin Triple을 이룹니다. 중력이 없어 천천히 생각할 수 있고,
  깬 단계는 이 기기에 표시됩니다. 퍼즐 메뉴에서 시작 보드와 피스 순서를 직접 정하고, 시험 플레이에서 판을 비우면 링크로 공유할 수 있습니다
- **CPU 대전:** 쉬움·쉬움+·보통·보통+·어려움·어려움+·최강 7단계. 같은 블록 순서로 동시에 시작해 조건을 충족하는 클리어로 쓰레기 줄을 보내고(T-spin·B2B·콤보·퍼펙트 클리어 가산),
  먼저 막히는 쪽이 집니다. 난이도별 전적이 남고, 결과 화면에서 양쪽 보드와 쓰레기 교환 장면을 다시 볼 수 있습니다
- **규칙:** Modern · Retro · Arcade 프리셋과 Custom 편집기(회전 SRS/ARS/킥 없음, 생성기 5종, 고정 방식 4종,
  넥스트·홀드·고스트·하드 드롭, ARE, IRS/IHS, 점수표, 조작감 고정). 기록은 모드 × 규칙 조합마다 따로 저장
- **조작:** DAS/ARR/SDF 조절, 키 변경(동작마다 2개), 게임패드(표준 배치)
- **점수:** T-spin(Mini 포함)·B2B·콤보·퍼펙트 클리어
- **기록 이름:** 기록 화면에서 이름을 저장하면 이후 기록에 표시됩니다. 이름과 기록은 이 브라우저에 저장됩니다.
- **내 기록과 달리기:** Sprint 40L · Ultra · Dig에서 같은 규칙 최고 기록 리플레이와 같은 블록 순서로 경쟁합니다.
- **훈련:** Sprint 40L 결과에서 이전 최고보다 많이 밀린 구간을 바로 연습할 수 있습니다. 비교할 구간이 없으면 피네스 실수 장면을 추천하고 같은 배치에 쓴 입력 횟수를 비교합니다. 연습: T-spin Double·Triple 자리, 퍼펙트 클리어 마무리,
  4줄·2줄 우물, 자유 쌓기, 피네스(최소 입력 판정). 피네스 훈련 10문제에서 목표 배치를 연습하고 실제·최소 입력과 추천 키 순서를 확인합니다. 판 통계에 피네스 실수 수
- **CPU 대전 입문:** 고정된 세 판에서 공격, 쓰레기 상쇄, 상쇄 후 반격을 한 수씩 연습합니다. 결과에서 공격·상쇄·전송 줄 수를 확인합니다.
- **빌드 연습:** 빈 판에서 4줄 우물을 만들고, 낮은 판에서 T스핀 더블 자리를 완성합니다. 비워 둘 칸과 다음 배치의 힌트를 보고 같은 판을 다시 시도할 수 있습니다.
- **파내기 훈련:** 고정된 판 6개에서 주어진 피스로 쓰레기 줄을 지웁니다. 구멍과 현재 판에서 도달할 수 있는 배치의 힌트를 차례로 보고 같은 판을 즉시 다시 시작할 수 있습니다.
- **입문과 진행도:** 도움말 또는 연습에서 이동·회전·홀드·첫 줄 지우기를 한 단계씩 익힙니다. 훈련과 퍼즐 완료는 백업할 수 있습니다. Sprint 기록에서 같은 규칙의 최근 20판과 최근 완주 중앙값을 봅니다.
- **리플레이:** 시드 + 입력 기록만으로 재생, 진행률과 한 프레임씩 보기, 파일로 저장·열기(열 때 결과를 다시 계산해 검증).
  기록표마다 상위 3개 기록의 리플레이를 남깁니다. 진행 막대로 원하는 시점에 가고(뒤로 가기 포함, ←→ 5초 · Shift+←→ 한 프레임),
  피네스 실수 · 오래 고민한 피스 · 주요 장면(T-spin · 4줄 · 퍼펙트)이 막대 위에 표시돼 [ ] 키나 버튼으로 건너뜁니다.
  리플레이는 링크(`#replay=`)나 파일로 공유하고, 받은 리플레이와 같은 블록 순서로 달릴 수 있습니다
- **화면:** 스튜디오 · 페이퍼 · 슬레이트 · 그라파이트 · 프레임 · 스톤 · 미드나잇 · 포레스트 · 화이트 보드 테마 9종(테마마다 블록 질감과 줄 삭제 연출이 다르고, 설정에 미리보기 그림), 착지 눌림과 짧은 이동, 색각 친화 팔레트,
  피스 색 직접 고르기(16색), 키 입력 표시, 시스템 라이트/다크. 효과를 전체로 설정하면 4줄 삭제·T스핀·백투백에 테마별 짧은 강조가 더해집니다. 가로로 눕힌 휴대폰에서는 보드 양옆에 조작 버튼이 놓입니다
- **소리:** 파일 없이 Web Audio로 합성한 효과음(이동·회전·줄 삭제·T-spin·콤보 등). 처음에는 꺼져 있고(공용 PC 배려), 설정에서 크기를 올립니다
- **접근성·편의:** 블록 무늬(색 없이도 피스 구분), 화면 읽기 알림(줄 삭제·레벨업·결과), 휴대폰 진동, 카운트다운 길이,
  고스트 진하기·격자 선, 조작감 프리셋(느긋하게~아주 빠르게), 터치 제스처 조작(밀어 이동·두드려 회전·튕겨 하드 드롭·위로 홀드),
  연습 모드 되돌리기(U), 처음 오신 분 안내와 머리글 도움말
- **언어:** 한국어 · English. 기본은 브라우저 언어를 따르고 설정에서 바꿀 수 있습니다
- **이어서 하기:** 모든 플레이 모드에서 창을 벗어나거나 닫을 때 진행 중인 한 판을 이 기기에 저장합니다. 메뉴의 이어서 하기에서 복원할 수 있고, 쉬는 동안 게임 시간은 흐르지 않습니다. 새 판으로 바꾸기 전에 확인합니다.
- **백업:** 설정·기록·리플레이·연습 진행도를 JSON 파일 하나로 저장합니다. 불러오기 전에 담긴 항목 수를 확인할 수 있고, 저장에 실패하면 기존 데이터가 보존됩니다.

## 개발

```bash
npm install
npx serve .        # 또는 아무 정적 서버. ES 모듈이라 file://로는 개발용 index.html이 안 열린다.
```

| 명령 | 하는 일 |
|---|---|
| `npm run build` | `deploy/index.html` 한 파일 생성 (file://로 더블클릭해도 동작) |
| `npm run build:pages` | `deploy-pages/` — 위 파일 + 설치형 앱(PWA) 파일. GitHub Pages용 |
| `npm run test:unit` | Node 단위 테스트 (코어·규칙·빌드 도구) |
| `npm run test:browser` | 배포본을 Chromium으로 열어 보는 테스트 (`npx playwright install chromium` 필요) |
| `npm run lint` / `npm run format` | ESLint / Prettier |
| `npm run typecheck` | JSDoc 타입 검사 (`tsc --checkJs`, 출력 없음) |

## CI

`.github/workflows/ci.yml` — 모든 push·PR에서 lint · 타입 검사 → unit/browser 테스트 → 모두 통과하면 단일 파일 빌드를
실행 페이지의 **Artifacts**(`tetri-sharp-<커밋 SHA>`)로 올립니다.

## 배포 (GitHub Pages)

`.github/workflows/pages.yml` — `main`에 push되면 `npm run build:pages` 결과를 GitHub Pages로 배포합니다.
배포본은 설치형 앱(PWA)이라 한 번 열면 인터넷 없이도 열리고, 휴대폰 홈 화면에 추가할 수 있습니다.

처음 한 번만:
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로.
2. 기본 브랜치를 `main`으로(Settings → General → Default branch). Pages 배포 환경은 기본 브랜치만 허용합니다.
