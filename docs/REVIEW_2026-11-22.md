# 기능 · UI/UX 깐깐 평가 (2026-11-22)

배포본(`deploy/index.html`)을 빌드해 데스크톱 1440×900, 노트북 1280×720, iPhone SE 세로, iPhone 13 가로에서
첫 화면 · 게임 · 일시정지 · 확인창 · 결과 · 통계 · 공유 · 리플레이 · 대화상자 9종을 찍어 보고, 모드 · 봇 · 대전 · 효과음 코드를 읽었다.

**총평:** 엔진 · 규칙 편집 · 리플레이 · 테스트는 수준급이다. 그러나 **기능은 넓고 깊이는 얕다.**
첫 화면의 입구가 20개 가까이 되지만 끝까지 붙잡을 깊이가 있는 콘텐츠는 Sprint 정도다.
휴대폰에서는 **누를 수 없는 버튼과 읽을 수 없는 글자**가 아직 있다.

심각도: **치명** = 못 쓰거나 잘못 씀 · **높음** = 읽기 어렵거나 크게 불편 · **보통** = 거슬림·일관성 · **낮음** = 다듬기.

## Part 1. 기능

### 1-1. 필요 없을 것 같은 것

| # | 기능 | 이유 |
|---|---|---|
| F1 | Endless | 중력이 레벨 1 고정, 끝나는 조건 없음(`js/modes/index.js` `ZEN`). 익숙해지면 영원히 안 죽어 "최다 줄" 기록은 실력이 아니라 버틴 시간만 잰다. Marathon · 연습 "자유 쌓기"와도 겹친다. 없애거나 속도가 계속 오르게 바꿔야 한다. |
| F2 | 첫 화면 "데이터"(백업 저장·불러오기) | 드물게 쓰는 기능이 첫 화면 한 블록을 차지한다. 설정 안으로. |
| F3 | 첫 화면 "리플레이 → 파일 열기" | 받은 리플레이는 링크(`#replay=`)로 열리므로 첫 화면에 둘 이유가 약하다. |
| F4 | "달리기" 입구 3중복 | 첫 화면 "내 기록과 달리기", 결과 구간 기록의 "최고 기록과 달리기", 리플레이 "이 기록과 달리기". 결과 · 리플레이 두 곳이면 충분하다. |
| F5 | 퍼즐 만들기(에디터) | 공유 목록 없이 링크만 주고받는 구조라 쓰일 일이 거의 없다. 들인 공에 비해 노출 가치가 낮다. |
| F6 | 휴대폰의 "키보드"·"게임패드" 설정 탭 | 휴대폰에서 쓸모없는데 탭 줄을 두 줄로 밀어낸다(U8). |

### 1-2. 너무 대충 만든 것

| # | 기능 | 문제 |
|---|---|---|
| F7 | CPU 봇(`js/ai/bot.js`) | 생성 위치에서 회전 → 좌우 이동 → 하드 드롭만 검토한다. 소프트 드롭 밀어 넣기 · 스핀 · T-spin을 한 번도 하지 않는다. 내다보기는 홀드 피스 하나 수준. 7단계 차이는 PPS와 차선 확률뿐이라 "최강"도 빨리 쌓고 4줄만 노린다. 받을 쓰레기가 평가 함수에 없어 수비 전환도 없다. |
| F8 | Master | 등급 · 구간 시간 제한 · 연출이 없고 결과는 "레벨 N"뿐 — 사실상 아주 긴 Marathon. Modern 고정 지연이 그대로라 20G 구간 긴장감도 약하다. |
| F9 | 퍼즐 30개 | 사실상 3종(판 비우기 1~4피스, TSD, TST). 난이도 순서가 들쭉날쭉(16번 3피스 → 17번 2피스, 23번 4피스 → 24번 3피스). |
| F10 | 일시정지 ↔ 첫 화면으로 | 일시정지는 "이 기기에 저장됐어요"라고 하는데 "첫 화면으로"를 누르면 "기록되지 않고 사라져요"라고 묻고 실제로 지운다(`js/main.js` `acceptConfirm` → `clearRun()`). 이어서 하기가 가장 필요한 흐름에서 저장을 버린다. |
| F11 | 의미 없는 결과 | 0.4초 게임 오버에도 PPS 30.00, "최고 기록 —", "순위 —", 빈 "구간 기록", 리플레이 저장 · 공유가 그대로 나온다. 게임 오버면 구간 기록 · 공유는 감춰야 한다. |
| F12 | 오늘의 도전 | 매일 Sprint 40L 고정이라 "오늘의" 느낌이 약하다. 요일별로 모드 · 규칙을 돌리면 매일 올 이유가 생긴다. |
| F13 | 통계 대화상자 | 줄 삭제가 없으면 "▶ 0회 항목 보기" — 어색하고 오른쪽 칸 전체가 빈다. |
| F14 | Endless 내부 id | id가 `zen`, 이름은 Endless. 기록 키 · 링크에서 헷갈린다. |

### 1-3. 부족한 것

| # | 부족한 점 |
|---|---|
| F15 | 장기 동기 없음 — 업적 · 해금 · 경험치 · 랭크가 없고 기록은 이 기기 안에만 있다. 비교 대상이 "과거의 나"뿐이다. |
| F16 | 배경음악 없음, 효과음 기본 꺼짐 → 첫 판이 완전 무음. 첫 실행 때 한 번 묻는 편이 낫다. |
| F17 | 사람과의 대전 없음. 서버가 어렵다면 같은 기기 2인 대전이나 리플레이 코드 비동기 대전을 키우는 게 차선. |
| F18 | CPU 상대의 개성 없음 — "T-spin 위주 · 콤보 위주 · 다운스택 위주" 같은 성향이 있어야 반복할 이유가 생긴다. |
| F19 | 정체성인 규칙 조합의 결과를 보여 주는 장치가 없다. Custom 규칙 공유 · 비교가 없어 혼자 하는 실험에서 끝난다. |

### 1-4. 재미가 없을 것 같은 것

- **Endless** — 속도도 목표도 그대로라 5분이면 질린다.
- **Master** — 등급 없이 999까지 가는 긴 작업.
- **퍼즐** — 비슷한 판 비우기 문제가 30번 반복.
- **CPU 상위 난이도** — 늘 같은 방식으로 4줄만 노려 패턴이 금방 보인다.
- **연습 메뉴** — 11개가 넘는 줄 목록에 추천 순서 · 잠금 · 완료 표시가 없어 숙제 목록처럼 느껴진다.

## 먼저 손볼 다섯 가지

1. 휴대폰 일시정지 · 결과 카드가 보드 밖으로 넘치지 않게(U1~U3)
2. "첫 화면으로"가 저장된 판을 지우지 않고 이어서 하기로 남기기(F10 · U11)
3. 휴대폰 리플레이 보드 크기 · 정보 칸 넘침(U4 · U5)
4. CPU 봇에 소프트 드롭 밀어 넣기 · T-spin 추가, 난이도별 성향(F7 · F18)
5. Endless는 속도 상승, Master는 등급 추가(F1 · F8)
