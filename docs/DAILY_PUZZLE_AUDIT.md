# 오늘의 퍼즐 검수

## 난이도 개편 후 90일

새 생성 규칙은 2026-11-29 이후 날짜에 적용한다. 이전 날짜의 퍼즐 코드 120개(2026-08-01~11-28)를 개편 전과 비교했고 모두 일치했다. 난이도 표시는 이전 날짜에도 새 기준을 적용한다.

2026-11-29부터 2027-02-26까지의 입문은 12개, 보통은 68개, 어려움은 10개였다. 90개 모두 본편 엔진에서 대표 입력을 재생해 성공했다. 그 기간의 첫 배치 함정 13개에서 판과 대표 풀이가 그대로 반복된 경우는 없었다.

같은 시작일에서 365일로 넓혀도 모든 대표 입력이 본편 엔진에서 클리어됐다. 입문 49개, 보통 272개, 어려움 44개였으며 첫 배치 함정 52개에 같은 판이나 같은 대표 풀이가 나온 날은 없었다.

- **판단 어려움**은 클리어까지 최소 다섯 수가 필요하다. 완주 가능한 첫 배치가 전체의 3분의 1 이하이고, 당장 유리해 보이지만 이후 두 수 이상 진행한 뒤 막히는 선택이 있어야 한다.
- 줄 삭제, 덮인 빈칸, 표면 요철, 홀드를 기준으로 유리해 보이는 수만 이어도 성공하는 후보는 제외한다. 어려움 후보에 대한 이 검사는 탐색 높이 안의 180° 우회도 포함한다.
- 대표 풀이의 이동·회전 부담은 **조작 난이도**로 따로 표시한다. 2026-11-29의 한 수짜리 끼워 넣기는 조작이 어려움이고 전체는 보통이다. 2026-12-02는 다섯 수가 필요하며 전체와 판단이 어려움, 조작은 입문이다.

이 검사는 정해진 탐색 높이와 제한 안에서의 추정값이다. 어떤 수가 자연스러워 보이는지에 대한 가중치는 실제 플레이 결과로 보정할 수 있다.

```sh
npm run audit:daily-puzzles -- 2026-11-29 90
```

## 개편 전 365일

**2026-11-26부터 2027-11-25까지** 날짜별 퍼즐을 생성했다. 365개 모두 대표 풀이의 90° 회전, 좌우 이동, 소프트 드롭, 홀드, 고정 입력을 본편 엔진에 재생해 성공을 확인했다. 고정 위치, 지운 줄, 스핀 판정도 비교했다. 예정된 유형을 다른 유형으로 대체한 날은 없었다. 기존 생성기와 비교한 365일의 퍼즐 코드와 유형은 모두 일치했다.

### 반복

| 비교 범위 | 반복된 판 | 비슷한 판 | 같은 대표 풀이 |
| --- | ---: | ---: | ---: |
| 앞선 모든 날짜 | 26 | 81 | 61 |
| 앞선 35일 | 8 | 16 | 18 |

판을 좌우로 뒤집은 경우도 반복으로 센다. 같은 유형에서 좌우 반전까지 고려했을 때 두 칸 이하만 다르면 비슷한 판으로 센다. 대표 풀이는 피스, 배치, 홀드, 삭제한 줄 수와 스핀을 비교하며 평행 이동과 좌우 반전을 같게 본다. 같은 날의 판과 대표 풀이가 둘 다 반복될 수 있다.

- **2027-02-02부터 02-08까지**는 앞선 35일과 비교했을 때 반복 지표에 걸린 날이 3일로 가장 많았다.
- **짧은 판 비우기**에서 같은 판 13일과 같은 대표 풀이 20일을 확인했다. **홀드 순서**에서 비슷한 판이 21일로 가장 많았다.

### 난이도

전체 등급은 입문 50개, 보통 180개, 어려움 135개였다. 판단 등급이 조작보다 높은 날은 199일, 조작 등급이 판단보다 높은 날은 52일이었다.

| 날짜와 유형 | 판단 | 조작 | 엔진 재생에서 확인한 차이 |
| --- | --- | --- | --- |
| 2026-11-30 · 4줄 우물 만들기 | 어려움 | 입문 | 첫 배치 12개 중 1개만 완주에 이어진다. 대표 풀이 4수 모두 상단에서 위치와 방향을 정하고 내려놓는다. |
| 2026-11-29 · 처마 아래 끼워 넣기 | 보통 | 어려움 | 대표 풀이는 한 수이며, 피스가 내려간 뒤 이동 한 번과 회전 두 번을 쓴다. 같은 방향으로 연속 이동하는 키 입력은 한 동작으로 센다. |

등급은 제한된 탐색과 대표 입력 경로에서 계산한 추정값이다. 플레이어가 체감하는 난이도와 조작 장치별 부담은 실제 플레이 피드백으로 보정할 수 있다.

### 재검수

```sh
npm run audit:daily-puzzles -- 2026-11-26 365
```

시작 날짜와 일수를 바꿔 다른 기간도 같은 기준으로 검사할 수 있다.
