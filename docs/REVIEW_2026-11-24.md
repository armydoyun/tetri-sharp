# 기능 · UI/UX 깐깐 평가 3차 (2026-11-24)

2차 평가(`docs/REVIEW_2026-11-23.md`) 뒤에 들어온 것을 본다: 앱 안 확인(`confirmButton`, `ask.js`), 기록 지우기, 누적 업적,
퍼즐 새 장 "4줄 만들기", CPU 난이도 사다리 조정, 리플레이 장면 목록, 휴대폰 제스처 방향 잠금, 키보드 포커스 처리, CI 정리.
이번에는 **1·2차에서 "해결"로 적은 것이 여전히 해결돼 있는지**도 다시 확인했다.

배포본을 빌드해 데스크톱 1280×800, iPhone 13 세로·가로, iPhone SE(영어)에서 화면 111장을 찍고, 새 코드(`js/input/gestures.js`,
`js/storage/achievements.js`, `js/ui/components.js`, `js/ui/ask.js`, `js/main.js` 결과·포커스 부분, `js/modes/puzzles.js`)를 읽었다.
콘솔 오류·경고는 없었고, 자동 UI 검수(네 화면 크기, 접근성 포함)는 0건이다.

**총평:** 화면의 "구멍"과 어긋남은 거의 사라졌다. 이번에 걸린 것은 **고치면서 새로 생긴 부작용**이다.
제스처 방향 잠금이 "내리며 밀어 넣기"를 막았고, 누적 업적은 연타 판으로 쌓을 수 있다.
그리고 **영어 화면**에서 번역 하나가 두 뜻을 덮어 결과 표에 "Rank"가 두 줄 나온다.

심각도: **치명** = 못 쓰거나 잘못 씀 · **높음** = 크게 불편하거나 잃는 것이 있음 · **보통** = 거슬림·일관성 · **낮음** = 다듬기.
번호는 2차에 이어 붙인다(F32~, U46~).

## Part 1. 기능

| # | 심각도 | 기능 | 문제 |
|---|---|---|---|
| F32 | 높음 | 휴대폰 제스처 방향 잠금(F31의 부작용) | 처음 움직임이 아래면 손을 뗄 때까지 세로로 잠근다. 그래서 **소프트 드롭으로 내리다가 옆으로 밀어 처마 아래에 넣는 동작**(밀어 넣기·T-spin 자리)을 한 번의 손가락으로 할 수 없다. 이전에는 됐다. 잠금은 지키되, 세로로 내려간 뒤 손가락이 **잠깐 멈추거나 가로로 확실히(두 칸 넘게)** 움직이면 가로 이동을 다시 허락해야 한다. 아래로 빠르게 쓸 때(하드 드롭)는 지금처럼 옆으로 새지 않게. |
| F33 | 보통 | 누적 업적 | 짧은 판(F21: 20초 안에 줄 0개 등)도 "100판"과 합계에 더해진다. 하드 드롭 연타로 1초짜리 판 100번이면 "100판"을 얻는다. 짧은 판은 합계에서 빼야 한다. |
| F34 | 보통 | 업적 문구 | "퍼즐 완주 · 퍼즐 30단계 모두"는 단계가 38개가 된 뒤로 틀렸다(조건은 "모든 단계"라 맞는데 글만 30). 숫자를 박지 말고 "모든 퍼즐"로. |
| F35 | 낮음 | 앱 안 확인 대화상자(`ask.js`) | 취소 버튼 이름이 다른 대화상자와 같은 "닫기"다. 묻는 창에서는 "취소"가 맞다. |
| F36 | 낮음 | 4줄 만들기 4피스 단계 | 빈칸이 네 줄에 넓게 흩어져(예: 28단계 JJJ+I) 처음 보는 사람에게는 꽤 어렵다. 같은 장 안에서 3피스 단계와 차이가 크다. 빈칸을 한두 덩어리로 모으는 조건을 더하거나 4피스 단계를 하나 줄인다. |

## Part 2. UI/UX

| # | 심각도 | 화면 | 문제 |
|---|---|---|---|
| U46 | 높음 | 결과·기록(영어) | "순위"(기록표 몇 위)와 "랭크"(D~S+ 실력 등급)가 둘 다 "Rank"로 번역돼, 결과 표에 **Rank가 두 줄** 나온다. 순위는 "Place"로. |
| U47 | 보통 | 결과 "구간 기록" 접힌 줄(영어, 휴대폰) | "Retry the same pieces · splits start at 10 lines"가 한 줄에 안 들어가 오른쪽이 잘리고 앞의 펼치기 표시도 잘린다. 줄을 바꾸게 하거나 짧게("Retry same pieces"). UI 검수가 못 잡은 이유도 확인한다(`<summary>`의 글자 넘침). |
| U48 | 보통 | 두 번 눌러 확정 버튼 | 한 번 누른 상태(정말 지우기)가 라이트 테마에서 거의 안 보인다(옅은 강조 배경 + 테두리). 되돌릴 수 없는 일의 확인인데 신호가 약하다. 주 버튼처럼 강조색 면으로 바꾸거나 경고 색을 둔다. |
| U49 | 낮음 | 휴대폰 가로 플레이 | 오른쪽 위(회전 버튼 위)가 여전히 크게 빈다. 계기판을 둘로 나눠 한쪽을 이쪽으로 옮기면 왼쪽 계기판도 덜 빽빽해진다. |
