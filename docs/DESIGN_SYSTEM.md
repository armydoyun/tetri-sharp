# Tetri# 디자인 시스템

게임과 웹 화면이 하나의 규칙으로 보이고 움직이도록 정한 약속이다. 새 화면이나 컴포넌트를 만들 때는 이 문서를 먼저 확인한다.
토큰은 `css/tokens.css`, 컴포넌트는 `css/components.css`, 배치는 `css/game.css`, 아이콘은 `js/ui/icons.js`에 있다.

---

## 1. 원칙

### 원칙 1 — 이모지 금지, 아이콘은 SVG만

- 이모지와 이모티콘은 **어디에도** 쓰지 않는다(문구·버튼·알림·코드 안 문자열 모두).
- 아이콘 역할을 하는 것은 **모두 SVG**다. 글자 기호(← → ↑ ↓ ✓ ✕ ★ ▶ 등)를 아이콘처럼 쓰지 않는다.
  - 화살표 키 이름도 키캡 안의 SVG로 보여 준다(`js/ui/keycap.js`).
- 문장부호(—, …, ·, ‘ ’)와 단위(°)는 글자로 써도 된다. 곱셈·무한대 같은 수학 기호는 쓰지 말고 말로 쓴다(`20배`, `즉시`).
- `tests/unit/design-rules.test.mjs`가 소스 전체에서 이모지와 금지 기호를 찾아 CI에서 막는다.

### 원칙 2 — 예상할 수 없게 위치가 바뀌는 UI 금지

사용자가 무언가를 눌렀을 때, 누른 요소나 그 주변 요소가 **밀리거나 튀면 안 된다**. 내용이 바뀌어도 크기는 그대로여야 한다.

| 상황 | 하지 말 것 | 할 것 |
|---|---|---|
| 조건에 따라 필요 없는 항목 | 숨기기(`display: none`) | **같은 자리에서 비활성** + 설명 줄에 쓸 수 없는 이유 |
| 때때로 생기는 알림·배지 | 생길 때 끼워 넣기 | **자리를 미리 잡아 둔다**: `.notice-slot`(두 줄 고정), `.is-invisible`(보이지만 않음) |
| 특정 상태에서만 쓰는 버튼 | 그때만 나타나기 | **늘 같은 자리**에 두고 비활성 (예: 규칙 "편집" 버튼) |
| 숫자·시간처럼 길이가 바뀌는 값 | 내용만큼 늘어나는 칸 | **고정 폭** 칸 + `tabular-nums` + 넘치면 말줄임 |
| 탭·세그먼트 | 선택되면 굵어지거나 커지기 | 칸 폭 동일, 바뀌는 건 **색만** |
| 상태 표시 | 버튼과 같은 줄에서 가운데 정렬 | 상태 칸을 **고정 폭 격자**로 분리 (리플레이 막대) |
| 스크롤바 | 생기고 사라지며 폭 변화 | `scrollbar-gutter: stable` |
| 보드 위 연출(카운트다운·액션 문구·패널) | 흐름 안에 넣기 | `position: absolute`로 **겹쳐서** 다른 요소를 밀지 않음 |

- `hidden` 속성(자리까지 없앰)은 **겹쳐 뜨는 패널**(메뉴·일시정지·결과·리플레이 막대)에만 쓴다.
- 줄 수가 바뀔 수 있는 영역(키 안내 등)은 `min-height`로 최대 줄 수만큼 자리를 잡는다.
- `tests/browser/build.test.mjs`의 "레이아웃 고정" 테스트가 상호작용 전후로 요소 위치를 재서 CI에서 막는다.

### 원칙 3 — 게임 입력을 절대 늦추지 않는다

UI 애니메이션은 색·투명도만, 120ms 이하. 키 입력이 애니메이션을 기다리는 일은 없다. 게임 안 연출은 설정의 "화면 효과"로 따로 조절한다.

## 2. 테마

- **UI**(머리, 정보 칸, 키 안내, 대화상자)는 기기 설정을 따라 **라이트/다크**가 바뀐다(`prefers-color-scheme`).
- **게임 화면**(`.surface-game`: 보드, 홀드·넥스트, 그 위에 겹치는 메뉴·일시정지·결과·리플레이 막대)은 **항상 다크**다.
  블록 색·고스트·효과를 한 벌로만 맞추기 위해서다.
- 구현: 다크 값은 `:root, .surface-game`에 함께 두고, 라이트 값은 미디어 쿼리 안의 `:root`만 덮는다 → `.surface-game` 안은 늘 다크.
- 캔버스 렌더러는 `--game-*` 토큰만 읽는다.

## 3. 색

| 토큰 | 다크 | 라이트 | 쓰임 |
|---|---|---|---|
| `--bg` | `#101114` | `#f3f4f6` | 페이지 바탕 |
| `--surface` | `#17191e` | `#ffffff` | 버튼·카드·입력 바탕 |
| `--surface-2` | `#1e2127` | `#eceef2` | 눌림·호버 바탕 |
| `--border` / `--border-strong` | `#2a2e36` / `#3d424d` | `#d8dbe1` / `#b9bec8` | 테두리 / 호버 테두리·키캡 |
| `--text` / `--text-dim` / `--text-faint` | `#e8e9ec` / `#9a9fab` / `#6b707b` | `#15171c` / `#555b66` / `#858b96` | 본문 / 보조 / 비어 있음 |
| `--accent` | `#7c9cff` | `#3a5bd9` | 대표 색(파랑). 라이트에서는 흰 바탕 대비 4.5:1 이상으로 진하게 |
| `--on-accent` | `#0b0d14` | `#ffffff` | 대표 색 위 글자 |
| `--scrim` | 다크 88% | — | 보드 위 패널 바탕 |

- 대표 색은 **파랑 하나**. 선택된 탭, 주 버튼, 로고의 `#`, 포커스 테두리, 기록 강조에만 쓴다.
- 블록 색은 게임 테마(`js/render/themes.js`)가 정하며 UI 장식에 쓰지 않는다. 색각 친화 팔레트는 설정에서 고른다(모든 테마에 적용).
- 색만으로 뜻을 전하지 않는다(비활성은 흐림 + 설명 글, 선택은 색 + `aria-pressed`).

## 3-1. 게임 테마

게임 화면(`.surface-game` 안의 캔버스)의 **모습만** 바꾼다. 메뉴·설정 같은 UI는 테마와 상관없이 이 문서를 따른다.
정의는 `js/render/themes.js` 한 곳에 있고, 설정 "게임 테마"에서 고른다. 기본은 **모던**.

| | 레트로 | 미니멀 | 모던 |
|---|---|---|---|
| 블록 | 픽셀 입체(밝은 위·왼 테두리, 어두운 아래·오른 테두리, 반짝이 픽셀) | 평면, 넓은 틈, 아주 살짝 둥근 모서리 | 둥근 모서리 + 세로 그라데이션 + 위쪽 빛 |
| 색 | 채도 높은 원색 | 채도를 낮춘 차분한 색 | 선명한 색 |
| 보드 | 단색 + 격자선 | 단색 + 점 격자 | 위가 살짝 밝은 그라데이션 + 옅은 격자선 |
| 고스트 | 같은 블록 25% | 윤곽선만 | 옅은 채움 + 윤곽선 |
| 움직임 | 칸 단위 | 칸 단위 | 약 50ms 미끄러짐(보이는 위치만, 판정·입력은 즉시) |
| 움직이는 피스 | — | — | 같은 색 빛 번짐 |
| 줄 삭제 | 두 번 깜빡이는 흰 섬광 + 네모 파편 | 옅게 사라지는 섬광 | 가운데서 퍼지는 빛 + 둥근 파편 |
| 하드 드롭 잔상·고정 반짝임·흔들림 | 있음 | 없음 | 있음(은은하게) |
| HOLD·NEXT 글자 | 굵은 대문자, 넓은 자간 | 가는 소문자 | 중간 굵기 대문자 |

- 접근성 설정은 테마 위에 덮인다: **블록 색**(테마 색 / 색각 친화), **화면 효과**(전체 / 줄임 / 끄기).
  "줄임"과 "끄기"에서는 미끄러짐·파편·흔들림·잔상이 모두 꺼진다.
- 새 테마를 넣을 때: `THEMES`에 항목을 추가하고 팔레트 8색이 서로 다른지, 블록·고스트 그리기와 연출 종류(`fx`)를 채운다.
  움직임이 있는 연출은 반드시 효과 "전체"에서만 동작하게 한다.

## 4. 글꼴

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--font-ui` | 시스템 글꼴(한글 포함) | 본문·설명·버튼 글 |
| `--font-display` | **Space Grotesk**(라틴·숫자만, 약 22KB, SIL OFL) → 없으면 시스템 | 로고, 숫자(시간·점수·레벨), 모드 이름, 키캡, 세그먼트 |

- 숫자는 항상 `font-variant-numeric: tabular-nums`(`.num`) — 값이 바뀌어도 폭이 같다.
- 글꼴 파일은 `assets/fonts/`에 있고 빌드가 data URI로 인라인한다(배포본은 여전히 한 파일).
- 크기 단계: `--text-xs 11` · `s 12` · `m 13` · `l 14`(기본) · `xl 16` · `2xl 20` · `3xl 24` · `4xl 32` · `5xl 40`.

## 5. 간격·모양·움직임

- 간격은 4px 단위: `--space-1 4` · `2 8` · `3 12` · `4 16` · `5 24` · `6 32`.
- 모서리는 **각진 편**: `--radius-s 2px`(키캡·배지·세그먼트 안 칸), `--radius-m 4px`(버튼·카드·입력·대화상자). 알약형 없음.
- 컨트롤 높이: `--control-h 36px`, 작은 것 `--control-h-s 28px`.
- 움직임: `--dur 120ms`, `--ease`. **색·투명도만** 바뀐다(자리 이동·크기 변화 없음). 동작 줄이기 설정이면 0ms.

## 6. 아이콘

- **직접 그린 선 아이콘**: 24×24 격자, 2px 여백, 선 굵기 1.75(`--icon-stroke`), 둥근 끝·둥근 모서리, 채움 없음.
- 색은 `currentColor`, 크기는 글자 크기의 1.15배(`.icon`).
- 정의는 `js/ui/icons.js`의 `ICONS` 한 곳. HTML에서는 `<span data-icon="이름"></span>`, JS에서는 `icon("이름")`.
- 아이콘만 있는 버튼은 반드시 `aria-label`을 단다. 장식 아이콘은 `aria-hidden`.

| 이름 | 쓰임 |
|---|---|
| `sliders` | 설정 |
| `edit` | 규칙 편집 |
| `play` / `pause` / `forward` / `restart` / `close` | 재생·일시정지·속도·처음부터/다시·닫기 |
| `menu` | 메뉴로 |
| `download` / `folder` | 파일로 저장 / 파일 열기 |
| `star` | 새 기록 |
| `reset` | 기본값으로 |
| `keyboard` / `gamepad` | 키 안내 머리 |
| `arrow-left` · `arrow-right` · `arrow-up` · `arrow-down` | 화살표 키캡 |

## 7. 컴포넌트

| 컴포넌트 | 클래스 | 규칙 |
|---|---|---|
| 버튼 | `.btn` `.btn-primary` `.btn-ghost` `.btn-small` | 아이콘(선택) + 글. 상태가 바뀌어도 테두리 두께·굵기·패딩 동일. 비활성은 40% 투명 |
| 세그먼트 | `.segmented > button[aria-pressed]` | 칸 폭 동일, 선택은 색만 |
| 키캡 | `.keycap` | 키 하나. 화살표는 SVG, 그 외 짧은 이름. 아래 테두리 2px |
| 배지 | `.badge` | 새 기록 등. 흐름 안에 둘 때는 `.is-invisible`로 자리 유지 |
| 알림 칸 | `.notice-slot` | 늘 두 줄 자리, 넘치면 두 줄에서 자름 |
| 대화상자 | `.dialog` + `fillDialog()` | 머리(제목·닫기 아이콘) / 몸통(스크롤, 폭 고정) / 발(알림 칸 + 버튼) |
| 설정 줄 | `.field-row` + `fieldRow()` | [이름 + 설명 한 줄 | 조작]. 설명 줄은 비어도 자리 유지. 비활성은 `.is-disabled` + 이유 |
| 슬라이더 | `.range` | 값 칸 10ch 고정 → 숫자가 바뀌어도 슬라이더 길이 동일 |
| 모드 카드 | `.mode-card` | 세 줄 모두 한 줄 고정(말줄임) |
| 정보 칸 | `.hud` | 폭 `--hud-width` 고정, 값은 한 줄 |

## 8. 배치

- `[보드 | 정보 칸]`은 고정 폭 격자. 정보 칸 숫자가 길어져도 보드가 움직이지 않는다. 좁은 화면(720px 이하)에서는 정보 칸이 보드 아래 3열로.
- 보드 위 패널은 넘치면 **패널 안에서** 스크롤한다(`justify-content: safe center`).
- 키 안내는 세 줄 자리를 미리 잡는다.

## 9. 문구

- 화면 언어는 **한국어**. 게임 용어(T-SPIN, PERFECT CLEAR, BACK-TO-BACK, 모드·프리셋 이름)는 영문 그대로.
- 해요체, 짧게. 쓸 수 없는 항목에는 이유를 한 줄로("홀드가 꺼져 있어 쓰지 않아요").
- 상표 이름은 쓰지 않는다(4줄 클리어는 QUAD).

## 10. 새 화면을 만들 때 확인할 것

1. 이모지·글자 기호 아이콘이 없는가 → SVG(`icon()`)로.
2. 무언가를 누르거나 값이 바뀔 때 다른 요소가 움직이지 않는가 → 숨기지 말고 비활성, 자리 잡기, 고정 폭.
3. 라이트·다크 둘 다에서 보이는가(게임 화면 안이면 다크만).
4. 숫자는 `tabular-nums`인가.
5. 아이콘만 있는 버튼에 `aria-label`이 있는가.
6. 키보드로 다 닿는가, 포커스 테두리가 보이는가.
