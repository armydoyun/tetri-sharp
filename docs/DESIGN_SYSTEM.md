# Tetri# 디자인 시스템

블록의 네 칸과 10칸 격자가 시각 언어의 출발점이다. 정돈된 여백, 단색 면, 가는 경계선으로 정보를 나눈다. 게임을 시작하기 전에는 규칙과 모드를 고르는 데 집중하고, 플레이 중에는 피스의 실루엣과 착지 위치가 먼저 읽히게 한다.

## 색과 표면

| 역할 | 라이트 | 다크 |
| --- | --- | --- |
| 페이지 배경 | `#f4f5ee` | `#171a17` |
| 카드와 대화상자 | `#fffef9` | `#212521` |
| 보조 표면과 호버 | `#edf0e6` | `#292f28` |
| 본문 | `#222820` | `#f1f2e9` |
| 보조 문구 | `#535f51` | `#b2baae` |
| 경계선 | `#dce1d5` | `#343b33` |
| 강조·선택·포커스 | `#3f5b29` | `#d6ed84` |

색은 `css/tokens.css`에서 역할별 변수로 관리한다. 시스템 색상 설정을 따르며, 홈의 블록 그래픽과 플레이 보드 주변은 어두운 표면을 공유한다. 실제 플레이 격자에는 선택한 보드 테마가 적용된다. 카드와 패널의 깊이는 면과 경계선으로 표현한다. 대화상자에만 화면 분리를 위한 그림자를 사용한다.

## 글자와 간격

- 본문, 워드마크, 게임 숫자에 시스템 산세리프를 사용한다. 시계와 점수에는 고정폭 숫자를 적용한다.
- 본문은 14px, 보조 정보는 12–13px, 대화상자 제목은 24px이다. 홈 제목은 화면폭에 맞춰 28–52px 사이에서 조절한다.
- 기본 간격은 4·8·12·16·24·32px다. 키캡은 4px, 버튼과 카드는 8px, 큰 표면은 12px 모서리를 쓴다. 세그먼트 안쪽 반경은 바깥쪽 반경에서 테두리와 안쪽 여백을 뺀 값이다.
- 아이콘은 24단위 격자, 단일 선 굵기와 현재 글자색을 사용한다. 아이콘만 있는 버튼에는 접근 가능한 이름을 붙인다.

## 화면과 컴포넌트

- **홈**은 브랜드 바, 게임 소개, 규칙 선택, 모드, 플레이 도구, 펼쳐 보는 조작법 순서로 배치한다. 도구는 연습과 기록, 리플레이 두 그룹의 한 줄 동작으로 구성한다. Sprint 40L 카드에 약한 강조를 주고 모든 모드에서 이름과 목표, 최고 기록을 같은 자리에 표시한다.
- **플레이**는 중앙 격자와 홀드·넥스트를 한 캔버스에 그린다. 넓은 화면에서 HUD는 보드 옆에, 좁은 화면에서는 위에 놓이고 홀드와 넥스트 폭을 줄여 중앙 격자를 넓힌다. 모드 이름과 일시정지는 상단에서 접근한다. 터치·리플레이 조작은 보드 아래에 둔다.
- **패널**은 카운트다운, 일시정지, 결과를 보드 위에 표시한다. **대화상자**는 제목, 탭, 스크롤 영역, 하단 동작을 공유한다. 설정 테마 카드의 미리보기는 실제 보드 색과 블록 팔레트를 사용한다.
- Sprint 결과에서 그 판의 구간 기록을 펼쳐 볼 수 있다. 비교는 시작할 때의 같은 규칙 최고 기록을 기준으로 한다. 리플레이 진행률은 읽기 전용이며, 한 프레임씩 보면 자동 재생을 멈춘다.
- 버튼과 카드의 포커스는 윤곽선으로 표시한다. 선택 상태는 시각 표시와 `aria-pressed`를 함께 적용한다. 값이나 탭이 바뀌어도 주변 컨트롤이 움직이지 않도록 숫자 폭과 알림 영역을 확보한다.

## 보드 테마

| 표시 이름 | 저장 키 | 보드 | 블록 |
| --- | --- | --- | --- |
| 스튜디오 | `modern` | 차콜 `#202421` | 선명한 무광색, 부드러운 모서리 |
| 페이퍼 | `retro` | 종이색 `#eeede3` | 잉크색, 낮은 모서리 곡률 |
| 슬레이트 | `minimal` | 푸른 회색 `#262d35` | 낮은 채도, 셀 사이 여백 |

저장 키를 유지해 기존 설정에서 새 테마를 이어서 선택할 수 있다. 세 테마는 단색 셀, 약한 격자, 윤곽선 고스트를 공유한다. 색각 친화 옵션을 켜면 블록과 고스트에 공통 팔레트를 사용한다. 테마 정의는 `js/render/themes.js`에서 관리한다.

## 모션

| 테마 | 한 칸 이동 | 착지 | 하드 드롭 잔상 | 줄 삭제 |
| --- | --- | --- | --- | --- |
| 스튜디오 | 42ms | 165ms · 높이 최대 20% 압축, 짧은 반동 | 최대 2.5칸 · 115ms | 가운데서 양옆으로 퍼지는 띠 · 205ms |
| 페이퍼 | 24ms | 115ms · 높이 최대 12% 압축, 바로 복원 | 최대 1칸 · 75ms | 왼쪽에서 오른쪽으로 진행하는 가는 선 · 155ms |
| 슬레이트 | 56ms | 215ms · 높이 최대 16% 압축, 완만한 반동 | 최대 2칸 · 155ms | 위아래로 벌어지는 평행선 · 245ms |

최대 압축은 여섯 칸 이상 하드 드롭했을 때 적용한다. 착지는 열별 아래 모서리를 기준으로 높이만 바꾼다. 줄이 지워지는 턴에는 줄 삭제 표시를 우선하고, 네 줄을 한 번에 지우면 표시를 조금 더 진하게 한다. 모든 효과는 보드의 테마 색을 사용하며 충돌, 점수, 리플레이 기록은 엔진 판정 그대로다.

‘줄임’은 위치 보간과 착지·하드 드롭 모션을 생략하고, 줄 삭제 위치에 고정 폭의 선만 175ms 표시한다. ‘끄기’는 효과를 즉시 생략한다. OS에서 동작 줄이기를 켜면 새 설정의 기본 효과 수준이 ‘줄임’이다.

## 변경 후 확인

`npm test`로 판정과 브라우저 흐름을 확인한다. 홈과 게임은 라이트·다크, 좁은 화면에서 각각 확인한다. 화면 탭에서 세 테마와 효과 수준을 바꾸고, 착지·줄 삭제·일시정지·다시 시작을 확인한다. 배포 전 `npm run build`와 `npm run build:pages`를 실행한다.
