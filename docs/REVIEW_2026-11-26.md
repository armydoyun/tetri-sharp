### 실행 순서와 근거 수준

1. **첫인상을 먼저 기록합니다.** 깨끗한 상태에서 화면을 열고, 첫 화면에 보이는 제목·주요 동작·가장 먼저 눈에 띄는 정보를 적습니다. 조작 전에 화면의 목적과 다음 행동을 한 문장으로 예상합니다.
2. **목표만 보고 과제를 수행합니다.** 아래 흐름의 ‘목표’를 읽은 뒤 실제 경로를 기록합니다. 도움말·검색·되돌아가기·반복 입력이 필요하면 어떤 지점에서 왜 필요했는지 남깁니다. 같은 작업을 다시 하며 단축키, 반복 동선, 입력 유지도 확인합니다.
3. **화면을 나란히 비교합니다.** 첫 화면·게임·결과, 편집·기록·설정 대화상자를 같은 배율로 캡처합니다. 빈 화면과 데이터가 찬 화면, 라이트와 다크, 데스크톱과 휴대폰을 나란히 봅니다. 같은 역할의 버튼, 제목, 빈 상태, 간격을 화면 사이에서 비교합니다.
4. **측정과 자동 검사로 확인합니다.** 크기·대비·넘침·정렬·포커스와 기능 결과를 재현합니다. 자동 검사가 겹침을 보고하면 스크린샷과 실제 클릭 영역을 함께 확인합니다. 측정 가능한 값과 검수자가 판단한 불편을 각각 적습니다.
5. **기대와 실제를 비교해 판정합니다.** 클릭 수나 소요 시간은 재현 가능한 비교에 사용합니다. 단독 검수에서 관찰한 사용성을 여러 사용자의 반응으로 일반화하지 않습니다. 실제 기기나 별도 사용자가 필요한 항목은 그 조건을 남깁니다.
