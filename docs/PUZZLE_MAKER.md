# 퍼즐 만들기 개선 계획

> 다음 업데이트의 목표: "퍼즐 만들기"를 **만들기 좋게**, 받은 퍼즐을 **쓰기 좋게**.
> 방향: 규칙을 갈아끼우는 Tetri#의 장점을 그대로 쓰는 **전문 편집기**. 단, 처음 온 사람은 지금처럼 바로 만들 수 있게
> **기본 화면 / 고급 설정** 두 층으로 나눈다.
> 오프라인 원칙은 그대로다. 서버·계정·외부 요청 없이 링크와 이 기기의 저장소(`localStorage`, 백업 파일)만 쓴다.

## 1. 정한 것

| 주제 | 결정 |
|---|---|
| 편집기 구성 | **기본 화면**(보드·피스 순서·목표) + 접힌 **고급 설정**(규칙 전체·중력·미리보기·처음 홀드 피스). 바꾼 고급 항목은 접힌 상태에서도 한 줄로 보인다 |
| 시작 | **시작 틀**에서 고른다: 빈 판, T-스핀 자리, 4줄 우물, 기본 퍼즐 N단계 복사, 받은 퍼즐 복사 |
| 피스 최대 개수 | 링크 길이와는 상관없다(피스 하나 = 한 글자). 판 높이에 맞춘 **넉넉한 안전선 50개**만 둔다 |
| 자동 확인 한도 | 탐색기는 **되는 만큼만**. 예산 안에 못 찾으면 "너무 길어서 자동으로 확인하지 못했어요. 시험 플레이로 직접 풀어 주세요" |
| 규칙 범위 | **규칙 전체**를 퍼즐에 담는다. 링크에는 **바탕 규칙 + 다른 항목만** 짧게(대부분 링크 100자 안팎) |
| 중력 | **없음(기본) / 20G / 규칙대로** 세 가지 중에 고른다 |
| 공유 조건 | 자동 확인으로 **풀 수 있다고 나오면 시험 플레이 없이도 공유**할 수 있다. 직접 풀어 본 퍼즐에는 "직접 풀어 봤어요" 표시를 따로 단다. 자동 확인이 안 되는 퍼즐(규칙대로 중력, 예산 초과)은 **직접 풀어야** 공유할 수 있다 |
| 받은 퍼즐 | 링크로 열면 **자동으로 "받은 퍼즐" 목록에 남긴다**. 지우기 쉽게 |
| 이번 범위 | **판 + 피스 + 목표**, **규칙 전체 + 중력 세 가지**, **목록·링크**까지. 나머지는 [7. 나중에](#7-나중에) |

## 2. 만들기 좋게

### 2-1. 보드 편집 (가장 시급)

- [x] **드래그로 칠하기**: 누른 칸의 반대 상태로 끌고 가는 칸을 모두 맞춘다(첫 칸이 빈 칸이면 채우기, 찬 칸이면 지우기).
      마우스·터치·펜을 Pointer Events 하나로. 보드 위에서는 스크롤을 막는다(`touch-action: none`).
- [x] **줄 단위 도구** — 칠하기 도구 세그먼트 [칸 | 한 줄 | 구멍 줄]
  - 한 줄 채우기·지우기
  - **구멍 하나 남긴 쓰레기 줄**: 누른 줄을 누른 열만 빈 쓰레기 줄로. 아래위로 끌면 같은 열에 구멍이 이어진다
    (계획의 "아래에 넣고 위로 밀기"는 "아래로 밀기" 도구와 겹쳐 이렇게 바꿨다)
  - 판 전체 지우기(`confirmButton()`으로 두 번 눌러 확정)
  - 위·아래·좌우로 판 전체 밀기, 좌우 뒤집기(미러 퍼즐)
- [x] **되돌리기·다시 하기**: 편집 기록 스택. `Ctrl+Z` / `Ctrl+Shift+Z`, 버튼도 둔다. 보드·피스·목표·고급 설정 변경 모두 포함.
- [x] **편집 높이 줄이기**: [8줄 | 12줄 | 20줄]. 줄이 적을수록 칸이 크다. 블록이 있는 높이보다 낮은 선택지는 고를 수 없고,
      판을 위로 밀어 블록이 넘치면 다 보이게 넓힌다.
- [x] **시작 틀** 드롭다운: 빈 판, T 자리, 4줄 우물, 퍼즐 N단계 복사. 고르면 판·피스가 바뀌고 되돌리기로 돌아갈 수 있다.
  - 3단계에서 **T-spin Double·Triple 자리** 틀과 **모든 단계 복사**(목표도 함께: 밀어 넣기·돌려 넣기는 "2줄 지우기")를 열었다. 4줄 우물은 "4줄 만들기" 목표.
  - 받은 퍼즐 복사는 받은 퍼즐 목록(4단계)과 함께.

### 2-2. 피스 순서

- [x] 최대 개수 6 → **50개**(안전선). 순서 표시는 길어지면 줄바꿈되는 칩 목록으로.
- [x] 순서 안에서 **고른 자리에 넣기·빼기·옮기기**. 칩을 눌러 고르면 그 뒤에 넣고, [← → 빼기] 버튼으로 옮기고 뺀다.
      키보드: 화살표로 칩 이동, Alt+화살표로 옮기기, Delete로 빼기. (끌어서 옮기기는 버튼으로 갈음했다)
- [x] 피스 버튼에 미니 모양 아이콘(`icons.js` `piece-I`…`piece-Z`).

### 2-3. 목표 고르기 (기본 화면) ✅

기본 퍼즐의 목표를 만든 퍼즐에서도 쓴다. 판정은 `js/modes/puzzle-goals.js`의 `goalOf`(기본 퍼즐·탐색기와 같은 함수).

- [x] 판 비우기 · T-spin Double · T-spin Triple · T-spin Mini · 4줄 만들기 · 콤보 이어 가기 · **N줄 지우기**(1~20줄, 지운 줄 합계)
- [x] [목표 고르기 | 줄 수] — 줄 수 드롭다운은 "N줄 지우기"에서만 켜지고 자리는 늘 남는다. 좁은 화면에서는 이름이 위 한 줄로.
- [x] 시작 틀을 고르면 그 틀의 목표로 바뀐다. 목표·규칙 바꾸기도 되돌리기에 남는다.
- [x] "못 풀어요" 문구는 목표에 맞춘다("이 피스로는 목표(T-spin Double)를 이룰 수 없어요.").

### 2-4. 고급 설정 (접힘) ✅

`<details id="puzzle-advanced">`. 항목 이름·설명은 규칙 편집 화면(`js/ui/rules.js`)과 같은 문구를 쓴다.

- [x] **바탕 규칙** [Modern | Retro | Arcade]: 고르면 그 규칙으로 아래 항목을 다시 채운다. 퍼즐의 바탕 규칙은 **홀드를 끈 것**(퍼즐은 홀드 없이가 기본).
      "내 규칙(Custom)"을 바탕으로 고르는 것은 빼었다 — 아래 항목으로 같은 조합을 만들 수 있고, 받는 쪽에는 그 규칙이 없다.
- [x] **퍼즐에 영향이 있는 항목**: 중력, 회전 시스템, 홀드, 처음 홀드 피스, 넥스트 미리보기, T-spin 판정, 고정 방식, 하드 드롭, 고스트, 미리 회전(IRS)·미리 홀드(IHS).
- [x] **퍼즐에서 쓰이지 않는 항목**(생성기·점수표·지연 시간 등)은 화면에 늘어놓지 않고 "바탕 규칙을 그대로 따라요"라고 한 줄로 알린다
      (계획의 "흐리게 보이기" 대신 — 항목 수가 많아 기본 화면을 가린다). 링크에는 바탕과 다르면 담는다.
- [x] **처음 홀드 피스**: 홀드가 꺼져 있으면 `disabled`(자리는 남긴다).
- [x] 접힌 머리에 바뀐 항목 요약 한 줄(`ruleSummary`, 예: "20G · 홀드(처음 I)"). 게임 화면 목표 줄에도 같은 요약을 붙인다.
- 퍼즐 모드의 홀드 규칙(`js/modes/puzzles.js`): 목록이 끝나면 홀드한 피스가 다음으로 나온다. 목록이 끝났는데 홀드 칸이 비어 있으면 홀드할 수 없다
  (엔진은 목록을 되풀이하므로 목록 밖 피스가 나오지 않게 — 엔진에 `mode.canHold` 훅을 더했다). 처음 홀드 피스는 피스 수에 들어간다.

### 2-5. 중력 세 가지 ✅

| 선택 | 어떤 퍼즐 | 자동 확인 · 첫 수 보기 |
|---|---|---|
| **없음**(기본) | 생각하는 퍼즐. 시간 압박 없음 | ✅ |
| **20G** | 피스가 나오자마자 바닥까지. 바닥을 따라 미끄러지거나 회전으로 턱을 넘어야 한다 | ✅ 탐색기에 "늘 바닥" 조건을 더했다 |
| **규칙대로** | 규칙의 중력·고정 시간 그대로. 시간 압박 퍼즐 | ❌ 푸는 사람의 DAS·ARR과 손 빠르기에 달려 있어 확인할 수 없다 |

- [x] 엔진: `makePuzzleMode`의 `gravityFor`가 퍼즐 설정에 따라 0 / 20G / 규칙 값.
- [x] 탐색기(`reachable`): 20G에서는 매 이동·회전 뒤 바닥까지 내린 자리만 상태로 둔다. 새로 나오는 피스는 IRS가 켜져 있으면 돌린 채로 나오는 자리도 본다.
      고정 지연이 없는 규칙에 20G면 나오자마자 그 자리에 고정된다. (리셋 한도 15회 같은 고정 지연 횟수는 세지 않는다 — 퍼즐에서 닿을 일이 거의 없다)
- [x] "규칙대로"는 자동 확인 버튼과 게임 중 첫 수 보기 버튼을 `disabled`로(자리는 남긴다), 확인 칸에 이유를 적는다. 이때는 직접 풀어야 공유한다.

### 2-5-1. 3단계에서 함께 고친 것

- **"못 풀어요"를 잘못 말하던 것**: 탐색기는 처음 판의 높이 위로는 피스를 놓아 보지 않았다(기본 퍼즐에 맞춘 지름길). 만든 퍼즐에서 위로 쌓아야 풀리는 판은
  "못 풀어요"로 나올 수 있었다. 이제 판 비우기는 블록 수로 정해지는 높이(쌓인 높이는 앞으로 지울 줄 수를 넘지 않는다)까지,
  다른 목표는 처음 판의 높이 안에서 먼저 찾고 못 찾으면 보이는 판 전체로 넓혀 찾는다. "못 풀어요"는 넓게 찾아 본 뒤에만 나온다.
  기본 퍼즐 70단계를 복사한 틀이 모두 1초 안에 풀린다(단위 테스트).
- 탐색기가 규칙의 T-spin 판정(없음)과 홀드를 따른다.

### 2-6. 풀이 자동 확인 ✅

- [x] 편집 중 **"풀 수 있는지 확인"** 버튼: 처음부터 끝까지 풀이를 찾는다(`findSolution`, `js/modes/puzzle-solver.js`).
  - 풀 수 있음 → "풀 수 있어요 · N수", 링크 공유를 켠다(1. 정한 것)
  - 못 풀어요 → "이 피스로는 판을 비울 수 없어요."
  - 예산 초과 → "너무 길어서 자동으로 확인하지 못했어요. 시험 플레이로 직접 풀어 주세요." 이때는 직접 풀어야 공유한다
- [x] **Web Worker로 돌린다.** 빌드가 `js/workers/solver.js`를 따로 묶어 본 스크립트 맨 앞 전역 문자열(`__TETRISHARP_SOLVER__`)로 넣고,
      `js/app/solver.js`가 Blob Worker로 띄운다(`file://`로 연 배포본에서도 된다). Worker를 쓸 수 없으면(개발용 모듈 실행, 막힌 환경)
      잠깐 뒤 화면 쪽에서 돌린다. 확인 중에는 **멈추기** 버튼(Worker를 버리고 새로 띄운다).
  - 게임 중 **"첫 수 보기"도 Worker로** 옮겼다. 찾는 동안 "첫 수를 찾는 중…", 단추는 "찾기 멈추기". 찾는 사이 피스를 움직이면 그 답은 버린다.
  - 목표는 함수라 Worker로 보낼 수 없어 종류·피스 수로 다시 만든다(`js/modes/puzzle-goals.js`, 기본 퍼즐도 같은 함수를 쓴다).
- [x] **풀이 보기** 스위치: 수마다 놓기 전 판과 놓을 칸(점선)을 판에 보여 준다. [← 1 / 3 →]로 넘긴다. 판을 누르면 편집으로 돌아온다.
- [x] 퍼즐이 바뀌면(코드가 달라지면) 확인 결과는 지우고, 찾던 확인은 멈춘다.
- [x] "직접 풀어 봤어요" 표시를 **받는 쪽**에도 보이기: 링크에 확인 표시(`e1` 자동 확인, `e2` 직접 풀어 봄)를 담고, 받는 쪽 목표 줄에
      "만든 사람이 직접 풀어 봤어요" 또는 "자동 확인으로 풀 수 있는 퍼즐"을 붙인다. 같은 퍼즐인지 가릴 때는 이 표시를 뺀 코드를 쓴다.

### 2-7. 미리 막아 주기 ✅

결과·경고는 확인 버튼 아래 두 줄 자리를 남긴 칸(`#puzzle-status`)에 보인다. 막지는 않고 알리기만 한다.

- [x] 블록 수 검사: 판을 비우는 순간 끝나므로 피스를 다 쓰지 않아도 된다. 앞에서 k개를 놓은 블록 수(칸 + 4k)가
      10의 배수가 되는 k가 하나도 없으면 알린다(계획의 "빈 칸 수 = 피스 수 × 4"는 너무 엄격해 바꿨다).
- [x] 이미 다 찬 줄(시작하자마자 지워질 줄) 경고.
- [x] 첫 피스가 나온 자리 바로 아래가 막혀 판으로 내려오지 못하면 경고(피스는 보이는 판 위 숨은 줄에 나오므로 "나올 자리"는 막힐 수 없다).

### 2-8. 2단계에서 함께 고친 것

- 시작 틀을 고른 뒤 같은 틀을 다시 고를 수 없던 것: 시작 틀은 고르면 바로 적용하는 메뉴라, 적용한 뒤 "시작 틀 고르기"로 돌아간다.

## 3. 쓰기 좋게 ✅

퍼즐 대화상자를 탭 셋으로 나눴다: **[기본 퍼즐 | 내 퍼즐 | 받은 퍼즐]** (`js/ui/puzzles.js`). 마지막에 본 탭을 기억한다.
저장은 `js/storage/custom-puzzles.js`(키 `tetrisharp:customPuzzles`). 읽을 때마다 검사해 허용된 값만 쓴다.

### 3-1. 내 퍼즐 목록 ✅

- [x] 만든 퍼즐을 이 기기에 **저절로 저장**한다: 판과 피스가 있어 링크로 보낼 수 있는 퍼즐이 되면 바로 저장되고, 고칠 때마다 같은 퍼즐(id)을 고친다.
      저장 버튼 대신 저절로 — 발 줄에 버튼을 늘리면 휴대폰에서 좁고, 닫았다가 잃는 일이 없다. 편집기 위에 저장 상태 한 줄.
      항목: id, 링크 코드(확인 표시 포함), 만든 날, 고친 날.
- [x] **내 퍼즐** 탭: 줄을 누르면 편집, 옆에 플레이 · 링크 복사 · 지우기(`confirmButton`). 줄은 `menuRow`(이름 · 목표 · 바뀐 규칙 · 확인 상태 · 고친 날).
  - 링크 복사는 자동 확인했거나 직접 풀어 본 퍼즐만(아니면 `disabled`, 이유는 툴팁).
  - 목록에서 플레이는 시험 플레이: 풀면 "직접 풀어 봄"이 저장된다. 결과의 "퍼즐 목록"은 내 퍼즐 탭으로.
  - "퍼즐 만들기"는 늘 새 퍼즐로 연다(전에 고치던 퍼즐은 내 퍼즐에 남아 있다). 시험 플레이 결과의 "퍼즐 편집"은 그 퍼즐로 돌아간다.
- [x] 백업 파일에 같이 넣고, 불러올 때는 바꾸지 않고 **합친다**(만든 퍼즐은 id로 — 더 나중에 고친 것, 받은 퍼즐은 같은 퍼즐끼리 — 푼 기록을 모아서).
- [x] 저장 한도 100개. 가득 차면 새 퍼즐은 저장하지 않고 편집기에서 알린다(있던 퍼즐은 계속 고칠 수 있다).

### 3-2. 받은 퍼즐 ✅

- [x] 링크로 연 퍼즐을 **저절로 "받은 퍼즐"에 남긴다**. 같은 퍼즐(확인 표시 뺀 코드)이면 하나로, 내가 만든 퍼즐이면 남기지 않는다.
      100개가 넘으면 가장 오래된 것부터 지운다. 줄마다 지우기.
- [x] 풀었는지 · 가장 빠른 시간 · 첫 수 보기를 썼는지("풀었어요 0:12.34", "풀었어요(첫 수 봄)", "아직").
- [x] "복사해서 편집" → 새 내 퍼즐로(확인 표시는 빼고 — 다시 확인하거나 풀어야 보낼 수 있다).

### 3-3. 제목·설명 ✅

- [x] 편집기 맨 위 [이름 | 설명] 입력(24자·60자). 링크에 담는다. 입력하는 동안은 그대로 두고, 칸을 떠날 때 되돌리기에 남긴다.
- [x] 받는 쪽: 게임 화면 제목(`#session-title`)이 퍼즐 이름, 목표 줄 끝에 설명. 목록 줄에도.
- [x] 사용자가 쓴 글은 `textContent`로만 넣는다. 공백은 한 칸으로 줄이고 앞뒤 공백은 뺀다.

### 3-4. 플레이 흐름 ✅

- [x] 만든 퍼즐에도 **"첫 수 보기"**(기본 퍼즐과 같은 버튼, 단축키 H). 홀드가 먼저면 "첫 수 · 홀드한 뒤 …". "규칙대로" 중력에서는 `disabled`. (3단계)
- [x] 결과 화면: 다시 하기 · 퍼즐 편집(시험 플레이일 때) · **퍼즐 목록**(내 퍼즐이면 내 퍼즐 탭, 받은 퍼즐이면 받은 퍼즐 탭).
- [x] 게임 화면 목표 줄에 목표 · 바뀐 규칙 요약 · 확인 표시 · 설명. (3단계·4단계)

## 4. 링크 형식 `2.` ✅

`js/modes/custom-puzzle.js`. 처음 형식 `1.`은 계속 연다(Modern, 홀드 없음, 중력 없음, 판 비우기). 새로 만드는 링크는 늘 `2.`.

```
#puzzle=2.<설정>.<높이 + 보드 hex>.<피스>[.<제목·설명>]
```

- **설정**: `_`로 이은 짧은 기호. 기본값이면 빠지고, 다 기본값이면 `-`. 모르는 기호는 건너뛴다(나중 형식과 섞여도 열리게).

  | 기호 | 뜻 | 값 |
  |---|---|---|
  | `o` | 목표 | `d` T-spin Double, `t` Triple, `m` Mini, `q` 4줄, `c` 콤보, `l<N>` N줄 지우기 (판 비우기는 생략) |
  | `g` | 중력 | `2` 20G, `r` 규칙대로 (없음은 생략) |
  | `b` | 바탕 규칙 | `r` Retro, `a` Arcade (Modern은 생략) |
  | `r` `z` `n` `h` `y` `d` `k` `a` `v` `s` `c` `f` `i` `j` | 바탕과 다른 규칙 항목 | 회전, 생성기, 미리보기, 홀드, 고스트, 하드 드롭, 고정(`m30x15`), 지연(`0x0`), 중력 값, T-spin, 점수표, 조작감 고정, IRS, IHS |
  | `p` | 처음 홀드 피스 | `I`…`Z` |
  | `e` | 확인 표시(공유할 때만) | `1` 자동 확인, `2` 직접 풀어 봄, `3` 둘 다 |

  예: T-spin Double · 20G · 홀드(처음 I) · 자동 확인 → `2.od_g2_h1_pI_e1.…`
  - 받은 값은 `sanitizeRuleBody`를 거쳐 허용된 값으로만 들어온다.
- **보드**: 쓰는 높이(1~20, base36 한 글자) + 그 줄들의 칸(4칸씩 hex). 빈 위쪽은 담지 않는다.
- **피스**: 한 글자씩, 최대 50개.
- **제목·설명**: base64url(UTF-8, `제목\n설명`), 제목 24자·설명 60자.
- 길이: 보통 30~60자, 규칙을 많이 바꿔도 100자 안팎. 코드 600자를 넘거나 글자가 맞지 않으면 "링크의 퍼즐을 읽을 수 없었어요".
- 피스가 7개 이상이거나 `2.` 형식인 링크는 이 업데이트 전 버전에서는 열리지 않는다.

## 5. 화면·디자인 약속 (AGENTS.md)

- 버튼·세그먼트·스위치·입력·목록 줄은 `js/ui/components.js`로만. 편집기 보드 칸(`puzzle-editor-cell`)은 지금처럼 그리드 칸으로 두되
  크기·여백은 CSS 변수로.
- 목표는 `segmented()` 또는 `dropdown()`, 중력 세 가지는 `segmented()`, 홀드 등 켜고 끄기는 `toggle()`.
- 고급 설정을 펴고 접을 때 기본 화면의 요소가 움직이지 않게(고급 설정은 아래에 붙는다).
- 상태가 바뀌어도 자리 그대로: 경고·확인 결과 문구는 높이를 남기는 칸에, 쓸 수 없는 버튼은 `disabled`.
- 지우기·판 전체 지우기는 `confirmButton()`.
- 새 문구는 한국어로 쓰고 `t()`로 감싸 `js/i18n/en.js`에 영어를 더한다. 아이콘은 `icons.js` SVG.
- UI 검수(`tests/helpers/ui-audit.mjs`) 네 화면 크기에서 넘침·잘림이 없어야 한다. 편집기는 휴대폰 세로에서 특히 확인.

## 8. 테스트 계획

- 단위
  - 링크 `1.`·`2.` 인코딩·디코딩, 하위 호환, 거절 사례, 규칙 차이 왕복(바탕 + 차이 → 같은 규칙)
  - 편집 동작(칠하기·줄 넣기·밀기·뒤집기·되돌리기)을 DOM 없는 순수 함수로 떼어 테스트
  - 목표별 판정이 기본 퍼즐과 같은 함수를 쓰는지
  - 풀이 확인: 풀 수 있는 판·없는 판·예산 초과, 20G에서 엔진과 같은 자리에 닿는지
  - 저장 목록: 추가·수정·삭제·한도·백업 합치기
- 브라우저
  - 드래그로 칠한 뒤 자동 확인 → 링크 복사 → 새 창에서 열기 → 받은 퍼즐 목록에 남는다
  - 고급 설정(20G·홀드)을 바꾼 퍼즐이 받는 쪽에서 같은 규칙으로 열린다
  - "규칙대로" 중력은 직접 풀어야 공유가 켜지고, 첫 수 보기가 꺼져 있다
  - 내 퍼즐 목록에서 편집·지우기(두 번 눌러 확정)
  - 휴대폰 세로·가로에서 편집기 UI 검수, 고급 설정을 펴고 접어도 기본 화면이 움직이지 않는다

## 9. 다시 보기 (2026-11-25): 만드는 중에 막히는 것

1~4단계가 다 들어간 편집기를 **만드는 사람의 흐름**으로 다시 써 봤다. 흐름은 판 칠하기 → 피스 넣기 → 확인 → 시험 → 고치기 → 공유다.
배포본을 데스크톱 1280×900과 휴대폰 390×844에서 스크립트로 조작했고, `js/ui/puzzle-editor.js`·`js/modes/puzzle-edit.js`를 읽었다.

### 찾은 것

| # | 심각도 | 무엇 | 근거 | 제안 |
|---|---|---|---|---|
| P1 | 높음 | **좌우 뒤집기가 판만 뒤집는다** | 판은 뒤집히는데 피스 순서(S·Z·J·L)와 처음 홀드 피스는 그대로다. 뒤집은 판에 원래 피스를 쓰면 대개 풀 수 없다(미러 퍼즐을 만들려는 바로 그 동작). | 뒤집을 때 S↔Z, J↔L도 바꾼다(피스 순서·처음 홀드). 되돌리기 한 번으로 함께 돌아간다. |
| P2 | 높음 | **판과 피스 버튼이 한 화면에 안 보인다** | 몸통에서 판은 471~715px, 피스 버튼은 1127~1219px(휴대폰, 보이는 높이 551px)다. 데스크톱도 판 362~617px, 피스 914~946px(보이는 높이 620px)다. 판을 보며 피스를 고르려면 매번 위아래로 스크롤해야 한다. | 피스 순서·버튼을 판 바로 아래(판 도구 다음)로 올린다. 넓은 화면은 두 칸([판 | 목표·피스·확인])으로. 이름·설명·시작 틀은 위 한 줄로 줄인다. |
| P3 | 보통 | **고칠 때마다 확인을 다시 눌러야 한다** | 칸 하나만 바꿔도 "풀 수 있음" 표시가 사라지고 `풀 수 있는지 확인`을 다시 눌러야 한다. 칠하며 바로 알 수 없다. | 편집이 멈추고 0.5초 뒤 Worker로 저절로 확인한다(짧은 예산). 결과는 같은 줄에 "풀 수 있음 · 3수" / "못 풀어요" / "확인 중". 긴 확인은 지금처럼 버튼으로. |
| P4 | 보통 | **게임 장면에서 퍼즐을 만들 수 없다** | 시작 틀은 정해진 틀·기본 퍼즐 복사뿐이다. 리플레이에서 "이 판으로 퍼즐"을 만들 길이 없다. 리플레이 장면 연습(`scene-practice.js`)은 이미 그 프레임의 판을 다룬다. | 리플레이 막대 옆에 "이 장면으로 퍼즐 만들기": 그 프레임의 판(색은 버리고 채움으로)과 다음 피스 N개·홀드를 편집기로 넘긴다. |
| P5 | 보통 | **피스를 빨리 넣는 방법이 없다** | 피스는 버튼만으로 넣는다. 키보드 I·J·L·O·S·T·Z 글자는 아무 일도 하지 않고, "TSZLJOI" 같은 순서를 붙여 넣을 수도 없다. 7개 넘는 순서를 넣으면 클릭이 많다. | 피스 칸에 포커스가 있을 때 글자 키로 넣기, 순서 글자를 붙여 넣으면 한 번에(되돌리기 한 번). 버튼에 글자 단축키 표시. |
| P6 | 보통 | **내 퍼즐을 복제할 수 없다** | 내 퍼즐 줄에는 플레이·링크·지우기만 있다. 같은 판의 변형(피스만 다른 쉬운·어려운 버전)을 만들려면 처음부터 다시 칠해야 한다. 받은 퍼즐에는 "복사해서 편집"이 있다. | 내 퍼즐 줄과 편집기에 "복제". 확인 표시는 빼고 이름 뒤에 "(사본)". |
| P7 | 낮음 | **밀기로 칸이 조용히 사라진다** | 맨 위·옆 칸이 있을 때 그쪽으로 밀면 밖으로 나간 칸이 지워지는데, 아무 알림이 없다(되돌리기는 된다). | 칸이 밖으로 나갈 밀기는 버튼을 끄거나(`disabled`), 밀었을 때 "칸 n개가 밖으로 나갔어요 · 되돌리기"를 알린다. |
| P8 | 낮음 | **편집기를 닫으면 되돌리기 기록이 사라진다** | 내 퍼즐을 다시 열면 되돌리기가 꺼져 있다. 실수로 닫았다가 다시 열면 그 전으로 못 간다. | 열려 있는 동안의 기록을 퍼즐 id별로 메모리에 남긴다(새로고침 전까지). |
| P9 | 낮음 | **블록 모양 도장·세로줄 도구가 없다** | 실제 게임 같은 쌓인 판을 만들려면 칸을 하나씩 칠해야 한다. 칠하기 도구는 칸·한 줄·구멍 줄뿐이다. | 칠하기 도구에 "피스 도장"(고른 피스 모양, 회전 키로 돌림)을 더한다. 세로 한 줄은 낮은 우선. |
| P10 | 낮음 | **시험 플레이에서 한 수 되돌리기가 없다** | 되돌리기(U)는 연습에서만 된다. 만든 사람이 시험하며 "이 수 대신 저 수"를 비교하려면 처음부터 다시 해야 한다. | 시험 플레이(내 퍼즐)에서만 되돌리기를 켠다. 받은 사람의 풀이·확인 표시에는 쓰지 않는다. |
| P11 | 낮음 | **이름만 적은 새 퍼즐은 닫으면 사라진다** | 판·피스가 없으면 저장하지 않는다는 안내는 있지만, 다시 "퍼즐 만들기"를 누르면 빈 편집기가 나온다. | 저장되지 않은 새 편집 내용은 이번 실행 동안 기억해 두고, 다시 열면 이어서 보인다. |

### 문제없던 것

- 드래그 칠하기와 한 번 끌기 = 되돌리기 한 번, 줄·구멍 줄 도구, 높이 바꾸기.
- 시작 틀을 고른 뒤 되돌리기.
- 시험 플레이 결과의 "퍼즐 편집", 시험 중 Esc → 편집기.
- 받은 퍼즐의 "복사해서 편집", 내 퍼즐 자동 저장(판·피스가 있으면).
- 풀이 보기 중 판 잠금. 링크 길이, 규칙 전체 담기.

### 고칠 순서 제안

1. **P1**(뒤집기 버그) · **P2**(배치): 작고 매번 부딪힌다.
2. **P5 · P6 · P7**: 빠르게 넣고 변형을 만드는 편의.
3. **P3**(저절로 확인) · **P4**(장면에서 만들기): 만드는 재미를 키우는 기능. 조금 크다.
4. **P8 · P9 · P10 · P11**: 다듬기.

### 처리 현황

| # | 상태 | 고친 방법 |
|---|---|---|
| P1 | 해결 | 좌우 뒤집기가 피스 순서·처음 홀드 피스의 S와 Z, J와 L도 바꾼다(되돌리기 한 번). 단위 테스트: 기본 판 비우기 단계를 뒤집어도 풀리고, 피스를 안 바꾸면 못 푸는 단계가 있다. |
| P2 | 해결 | 700px 이상은 [판·칠하기 도구 | 피스 순서·피스·확인] 두 칸이다. 좁은 창은 판 바로 아래에 피스를 둔다. 1280×800에서는 처음 화면에 판과 피스 버튼이 함께 보인다. |
| P3 | 해결 | 고치기를 멈추고 0.6초 뒤 Worker로 저절로 확인한다. 다시 고치면 멈추고, 포커스는 옮기지 않는다. 피스가 12개를 넘거나, 미리 알려 줄 것이 있거나, 사용자가 멈춘 퍼즐은 버튼으로만 확인한다. |
| P4 | 해결 | 리플레이 막대에 "퍼즐로"를 둔다. 그 프레임의 판(채움)과 지금 피스 + 다음 피스, 홀드(있으면 홀드를 켠다)로 새 내 퍼즐을 연다. 닫으면 리플레이로 돌아간다. |
| P5 | 해결 | 피스 칸에서 I J L O S T Z 키로 넣는다. "TSZ"·"t s z"·"I, O, T"를 붙여 넣으면 한 번에 들어간다(되돌리기 한 번, 다른 글자가 섞이면 넣지 않는다). |
| P6 | 해결 | 내 퍼즐 줄에 "복제해서 편집"을 둔다. 이름 뒤에 "사본"을 붙이고, 확인 표시는 뺀다. |
| P7 | 해결 | 밀기로 칸이 밖으로 나가면 "칸 n개가 판 밖으로 나가 지워졌어요"라고 알린다. 일부러 바닥 줄을 지우는 쓰임은 그대로 둔다. |
| P8 | 해결 | 내 퍼즐마다 되돌리기 기록을 메모리에 남긴다(새로고침 전까지). |
| P9 | 해결 | 칠하기 도구 "도장"을 더했다. 누른 칸이 가운데가 되도록 고른 피스 모양을 찍고(O는 누른 칸이 왼쪽 위), 다 찬 자리를 다시 누르면 지운다. R이나 단추로 돌린다. 판 밖이면 찍지 않고 알린다. 올리거나 포커스한 칸에 미리보기를 보인다. |
| P10 | 해결 | 내 퍼즐 시험 플레이에서 한 피스 되돌리기(U·버튼)를 쓸 수 있다. 실패 결과에서 되돌리면 그 수 앞으로 판에 돌아간다. 받은 퍼즐·기본 퍼즐에는 쓰지 않는다. |
| P11 | 해결 | 저장 전 새 퍼즐(이름만 적은 것 등)은 닫아도 초안으로 남는다. 다시 "퍼즐 만들기"를 누르면 이어서 연다. |
| P12 | 해결 | (고치다 찾음) 이름·설명만 고쳐도 "직접 풀어 봄"·자동 확인이 사라졌다. 이제 확인 표시는 이름·설명을 뺀 퍼즐에 붙는다. |
| (덤) | 해결 | 드롭다운: 누른 단추를 화면에 보이게 하는 스크롤이나 휴대폰 관성 스크롤이 열자마자 목록을 닫던 것. 연 뒤 0.15초 동안의 스크롤은 무시한다. |
