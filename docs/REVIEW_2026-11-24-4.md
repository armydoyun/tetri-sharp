# 기능 · UI/UX 깐깐 평가 4차 (2026-11-24)

3차 평가(`docs/REVIEW_2026-11-24.md`) 뒤에 들어온 것을 본다.
- 퍼즐 새 장 넷: 처마 밀어 넣기, 콤보 이어 가기, 돌려 넣기, T-spin Mini
- 휴대폰 제스처 밀어 넣기 수정
- 테마 미리보기(작은 게임 화면 + 견본 칩), 원칙에 맞춰 다시 짠 테마 아홉 가지
- 설정 화면 색 정리

배포본을 빌드해 화면 56장을 찍었다. 크기는 데스크톱 1280×800, iPhone 13 세로·가로, iPhone SE(영어)다.
- 퍼즐 목록과 새 장마다 첫 단계(시작·실패 결과)
- 업적, 설정 테마, 규칙 편집(휴대폰 포함)
- 밝은 테마 + "화면 색 따르기" 게임 화면

콘솔 오류·경고는 없었다.

심각도: **치명** = 못 쓰거나 잘못 씀 · **높음** = 크게 불편하거나 잃는 것이 있음 · **보통** = 거슬림·일관성 · **낮음** = 다듬기.
번호는 3차에 이어 붙인다(F37~, U50~).

## 찾은 것

| # | 심각도 | 화면 | 문제 |
|---|---|---|---|
| U50 | 높음 | 휴대폰 규칙 편집(사용자 제보) | 창 전체가 스크롤될 것처럼 생겼는데 실제로는 아래 작은 칸만 움직인다. 내 규칙 줄·프리셋 줄·탭이 모두 위에 고정돼 몸통이 창 높이의 22%였다. |
| F37 | 높음 | 퍼즐 결과 | 퍼즐은 원래 피스 몇 개로 금방 끝난다. 그런데 결과에 "너무 일찍 끝난 판이라 공유하지 않고 마지막 판으로 남기지 않아요"가 나왔다. 뜻 없는 점수·레벨·최고 기록·순위 줄도 함께 나왔다. 짧은 판 규칙(F21)이 퍼즐까지 덮었다. |
| U51 | 보통 | 퍼즐 목록 | 장이 늘면서 맨 위 설명 문단이 휴대폰에서 일곱 줄이 됐다. 단계 칸이 화면 아래로 밀린다. |
| U52 | 보통 | 테마 칩(영어, iPhone SE) | "Blueprint"가 "Blueprin / t"로 글자 중간에서 꺾인다. |
| U53 | 보통 | 휴대폰 테마 미리보기 | 미리보기가 커서 처음 열면 칩이 첫 줄만 보인다(3차 이후 보고). |
| F38 | 낮음 | 콤보 퍼즐 | 계기판에 지금 콤보 수가 따로 없다. 줄을 지울 때 보드 위에 "콤보 +n"이 뜨고, 실패하면 바로 끝나므로 남긴다. |

## 처리 현황

| 항목 | 상태 | 고친 방법 |
|---|---|---|
| U50 | 해결 | 좁거나 낮은 화면에서는 내 규칙·프리셋 줄을 몸통 맨 위로 옮겼다. 이 두 줄은 몸통과 함께 스크롤되고, 탭만 고정한다. 화면을 돌리면 그 배치로 다시 그린다. 탭이 있는 대화상자는 고정된 탭과 스크롤 몸통 사이에 경계선을 둔다. **UI 검수에 "스크롤되는 몸통이 창 높이의 40% 미만" 검사를 더했다**(예전 배치에서 22%로 잡히는 것을 확인). |
| F37 | 해결 | 퍼즐은 짧은 판으로 치지 않는다. 결과 줄은 퍼즐에 맞게 시간 · 쓴 피스(1 / 3) · 줄 · 깬 단계(0 / 70)로 바꿨다. 브라우저 테스트가 확인한다. |
| U51 | 해결 | 맨 위 문단을 한 줄("장마다 쉬운 것부터 차례로 풀어요.")로 줄였다. 장마다 제목 아래에 한 줄 목표를 둔다. |
| U52 | 해결 | 360px 이하에서는 칩 이름을 한 단계 작게 하고 단어 중간에서 꺾지 않는다. |
| U53 | 해결 | 600px 이하에서 미리보기 폭을 줄여(최대 210px) 칩이 함께 보이게 했다. |
| F38 | 의도 | 위 이유로 남긴다. 콤보 장을 더 늘리면 다시 본다. |
